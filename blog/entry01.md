## My project.
Two things I enjoy very much is math and games. Therefore, for this project, I decided to make a somewhat math/number game taking heavy inspiration from a game I saw some kids playing while I was at a job over the summer. Obviously there may be some tweaks but in short, you will be given numbers and need to come up with a set value using symbols (addition, subtraction,etc). It is my hope that this project will help nurture some math skills and critical thinking skills because I understand that not everyone excels at quick calculations. 
## My tool.
Like last year, we'll be learning a tool, something that we can use to helps us while making the project. My tool is [Math JS](https://mathjs.org/) because it deals with, Math. After looking into it, it definelty seems to be a good choice because this project will be math heavy, having something can is built for math is something I believe a good choice for my tool. It's main appeal to me so far is its ability to do evaluate expressions without doing anything complicated using `math.evaluate(expression)`.
